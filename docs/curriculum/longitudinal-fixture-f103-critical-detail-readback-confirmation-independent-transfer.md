# F103 — Critical-detail read-back, correction closure, action-safe confirmation and independent unseen transfer

**Status:** design-only curricular acceptance fixture; **UNSUPPORTED** until executable assertions run against a named exact engine HEAD. Not a shipped speech-recognition, identity-verification or booking system; not a reproduced production defect, CEFR certification or evidence of improved real-learner retention. Pre-A1 frozen; A1–C2 unavailable.

**Contract:** docs/curriculum/longitudinal-instructional-adaptation.md. F33 requires genuinely unseen transfer; F37/F38 distinguish selected from actually rendered assistance; F47/F48 preserve noncompensatory CEFR evidence; F49 accessibility; F50 soft-interest breadth; F53 language variety/register; F54 communication repair; F74 cross-source fidelity; F76 information-gap questioning; F80 source/version updates; F85 permission/authority; F89 correction; F94 quantity bounds; F95 deadlines; F99 multipart responses; F100 compositional integrity; F101 interruption continuity; F102 speaker/recipient attribution. **Distinct construct:** when a real versioned CEFR-linked interaction requires **transmitting or confirming an exact, consequential detail** (a time, quantity, reference string, spelling, destination or other source-defined field), can the learner independently identify which detail must be exact, perform an appropriate **read-back/confirmation cycle**, incorporate an authorized correction, and act or relay only after the detail is sufficiently grounded? F54 tests repair after breakdown generally; F76 tests asking for missing information; F103 isolates **field-specific exactness, closed-loop confirmation and post-correction action safety**. The task may legitimately allow approximate phrasing for noncritical fields. No universal requirement to spell everything, use a particular alphabet, memorize arbitrary codes, or request confirmation on every turn.

## Six synthetic longitudinal histories

- **A — One character changes the recipient action.** In a fictional source-authored handoff, a recipient needs the reference string **R0-M7** (R, zero, hyphen, M, seven) to retrieve the right mock parcel. Learner A confidently relays **RO-M7** (letter O), producing a wrong match. Learner B independently reads back “R, zero, hyphen, M, seven” and waits for the authorized recipient's confirmation before submitting it. A matched source world deliberately uses **RO-M7**, so the verdict must reverse. A separate control explicitly permits case-insensitive matching but not zero/O substitution. Later unseen transfer changes token family, length, ambiguity and task outcome. Do not grade visual acuity or code memorization in place of the source-required communicative action.

- **B — Date, clock time and local interpretation.** A fictional meeting notice gives **Thursday 12 November, 09:30 in the organizer's stated local time**; the recipient works in another time zone and asks whether “nine thirty” means their own time. Learner A relays only “Thursday at nine thirty” and the recipient books the wrong slot. Learner B independently confirms the source's zone/date and either converts it accurately using task-provided conversion rules or requests the missing zone if absent. A control source explicitly says both participants share one local time zone, where a concise reply is sufficient. A text-only source cannot be scored as auditory number comprehension; calendar ambiguity and date conventions must be source-grounded.

- **C — Correction must close the confirmation loop.** In a fictional supply request, the authorized sender first says **14 units**, then corrects it to **40 units** before the learner submits the request. Learner A repeats the first number fluently or says “okay” without relaying the correction; the recipient orders 14. Learner B independently reads back “Forty units, not fourteen,” obtains source-permitted confirmation and transmits 40. A matched historical-report task asks “What was the original quantity?” and correctly accepts 14 **with attribution**. Another source world provides no accessible correction, making the supposedly corrected value unsupported. Later unseen transfer changes correction direction, unit and downstream decision.

- **D — Not every number needs exactness or repeated confirmation.** In a source-authored travel exchange, the speaker estimates a walk as “about 10–15 minutes” but supplies a **precise platform number 6** required to board. Learner A rigidly demands an exact walking duration while loosely relaying “platform five or six.” Learner B preserves the approximate duration and independently confirms the consequential platform number. A control task explicitly asks for a rough platform-area estimate rather than a platform instruction, changing what precision is justified. A different legitimate register or confirmation phrase can pass; compulsive clarification without information gain is not rewarded.

- **E — Assisted read-back wins immediately, independent correction transfer wins later.** For matched early sessions targeting the same real source-required CEFR confirmation can-do, READBACK_CONTRAST yields fast correct answers while a tutor-completed field map is visible; CORRECTION_CHAIN_ROLEPLAY initially yields slower unaided read-backs and some repair. In **later distinct real sessions**, genuinely unseen interactions change critical field types, correction placement, recipient role and permitted confirmation forms. The synthetic learner trained with roleplay independently transmits more correct final details and avoids more premature actions despite lower immediate assisted accuracy. Match or disclose baseline proficiency, field length/type, ambiguity, source authority, stakes, task difficulty, practice dose, feedback, language variety/register, topic familiarity and modality/accessibility. Record the **actually rendered** next method and keep sampling alternatives; do not infer that roleplay is universally best.

- **F — Favorite-topic overfit, out-of-order correction, cue leak and inaccessible channel.** A learner reliably reads back fictional game-room codes but confuses neutral class-room references and unfamiliar community-event details of comparable length and ambiguity. A tutor's completed read-back was rendered before the first assessed reply but its telemetry arrived late; a different read-back was selected but never displayed. Two offline sessions reuse a local event ID; an authoritative correction arrives after a stale cached source; a rubric revision authorizes a regional spoken digit form; an eligible delayed probe is offered but never completed. An audio stimulus makes zero/O indistinguishable and lacks an accessible disambiguating response. Reconstruct trusted source/render chronology, deduplicate only true session-qualified replays, quarantine incompatible source/ledger/rubric versions, preserve unknown follow-up and review debt, avoid penalizing inaccessible distinction, rotate topic contexts and require invariant independence/recipient-action/next-method verdicts across receipt permutations.

## Nine acceptance assertions

1. **Real CEFR applicability and critical-field boundaries.** A–F provide a real versioned descriptor/can-do, blueprint/prerequisites, source-authored communicative task, authorized source and recipient, target language/variety/register, accessible channel, frozen field ledger and normalization, recipient goal, rubric/evaluator, assistance policy, independence threshold, required skills, reviews, delayed/unseen probes and exit gate. No source-required exact-detail exchange means NOT_APPLICABLE; missing mapping or unadjudicable value means UNSUPPORTED, not an invented graduation requirement.

2. **Exactness and source-approved normalization.** A/B/D preserve field type, unit, punctuation, leading zero, character identity, date/time-zone anchor and allowable approximate ranges according to the frozen rubric. Matched source worlds changing one critical character, unit or zone must change the expected recipient action. Do not reward verbatim copying when the learner fails to use the value appropriately.

3. **Confirmation closure versus superficial agreement.** A/C/D distinguish a learner-authored read-back, the authorized interlocutor's actual confirmation, unresolved ambiguity and a merely polite “okay.” Do not mark confirmation complete or authorize an irreversible action from an unanswered read-back, silence, a tutor echo or an unrelated acknowledgment. Where the source task explicitly permits direct action without a read-back, unnecessary confirmation is not a mandatory extra gate.

4. **Corrections, authority and current-versus-historical detail.** B/C/F honor authorized source chronology and corrections; superseded values cannot drive current action. A historical-report question may correctly state the old value **with attribution**. An inaccessible correction or conflicting authority yields bounded clarification or UNSUPPORTED, never fabricated certainty.

5. **First independent read-back and actual cue provenance.** A/C/E/F adjudicate the first learner-authored recipient-facing move using trusted **actually rendered** tutor/interlocutor chronology. A displayed completed token, corrected number, highlighted character or ready-made reply before the move makes affected evidence assisted; assigned-but-unrendered support does not. An authorized interlocutor's response under the frozen confirmation protocol is legitimate stimulus; out-of-protocol answer revelation is coaching. Late telemetry cannot promote coached correctness.

6. **Delayed genuinely unseen independent detail transfer.** A–F require distinct real sessions, meaningful delay, new source-authored details with changed field type, ambiguity, correction timing, recipient role and action stakes, first unaided replies and observable source-defined recipient outcomes. Replaying the same token, memorizing a tutor-provided script, assisted repair or missing follow-up cannot establish durable mastery. Report eligible/offered/rendered/completed/missing denominators.

7. **Comparable instruction, accessibility and topic breadth.** B/E/F match or disclose critical field count/type/length, baseline proficiency, ambiguity, source authority, task burden, feedback, practice dose, language variety/register, modality/accessibility and preferred/adjacent/neutral/unfamiliar topic exposure. Protect shared CEFR objectives, noncompensatory receptive/productive skills, due reviews and exit gates. Inaccessible audio, missing captions, unavailable speech recognition or non-equivalent transcription are confounds, not learner deficits.

8. **Reversible outcome-based adaptation and replay invariance.** E/F log feasible candidates, selected/assigned/**actually rendered** method, completed later independent recipient outcomes, uncertainty/confounds, exploration and next-choice rationale. Stronger delayed unaided outcomes may reverse immediate assisted-score preferences without permanent learning-style labels; sparse/conflicted evidence falls back to BALANCED_DEFAULT. Session-qualified deduplication, frozen source/ledger/rubric versions and trusted correction/cue chronology must yield identical detail, independence, review-debt and next-method verdicts across receipt permutations; unresolved conflicts fail closed.

9. **Assertion-level audit and bounded claims.** A–F emit exact source/task/ledger/rubric/evaluator IDs, source-authorized value and normalization, first/final learner-authored read-back, correction and confirmation provenance, recipient interpretation/action, rendered cues, delayed/unseen denominators, confounds, replay permutations and PASS/FAIL/UNSUPPORTED per assertion. Documentation CI is not executable confirmation evaluation, verified audio capability, a CEFR award or proof of improved human retention.

## Required evidence and release gate

An **executable fixture PASS** requires a named exact engine HEAD and command, deterministic seed/clock, real source-linked CEFR tasks that genuinely require precise-detail communication, validated multilingual/variety-aware exactness and confirmation rubrics, frozen critical-detail ledger and correction authority, accessible source stimuli, trusted actually rendered cue chronology, first unaided learner-authored read-backs, source-defined recipient interpretations/actions, completed delayed genuinely unseen detail transfer with denominators, comparable method/topic/modality/accessibility exposure, protected required skills/reviews, receipt-order permutations, reversible next-method traces and assertion-level verdicts. Missing real mapping, valid normalization, reliable chronology, accessible disambiguation, recipient-action adjudication or completed follow-up remains UNSUPPORTED/unknown.

Any claim that adaptation **improves durable independent critical-detail communication** additionally requires separately reviewed real-learner longitudinal evidence against a credible balanced comparator, multilingual/variety and accessibility validation, human adjudication, privacy/subgroup-harm review and an ethically reviewed pilot. **A strong tutor helps learners check the detail that matters, incorporate the correction that counts, and act only on what the recipient actually confirmed.**
