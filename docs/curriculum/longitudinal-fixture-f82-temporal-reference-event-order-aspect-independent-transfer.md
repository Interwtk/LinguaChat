# F82 — Temporal reference, event order and aspect in independent communicative transfer

**Status:** design-only curricular acceptance fixture; **UNSUPPORTED** until executable assertions run against a named exact engine HEAD. Not a shipped temporal-language evaluator, CEFR certification, reproduced production defect or evidence of improved human learning. Pre-A1 frozen; A1–C2 unavailable.

**Contract:** `docs/curriculum/longitudinal-instructional-adaptation.md`. F31 prevents transient learner state from masquerading as method effects; F33 requires genuinely unseen transfer; F37/F38 distinguish delivered instruction and tutor-origin cues; F47/F48 preserve source-defined noncompensatory mastery; F49 protects accessibility equivalence; F50 protects topic breadth; F53 accepts valid language varieties; F70 covers contextual lexical selection; F71 covers discourse reference; F72 tracks task constraints; F74 guards source fidelity; F80 covers **propagating authoritative updates across asynchronous handoffs**; F81 covers quantifier, negation and exception scope. **F82 isolates a different source-required communicative construct:** correctly interpreting and independently expressing *when an event occurred relative to speaking/reference time, which event preceded another, and whether an event is ongoing, completed, repeated or merely planned* when these distinctions materially affect a source-defined communicative task. A fluent narrative, correct calendar date or verb form copied from a tutor does not alone establish independent temporal meaning. Conversely, exact tense morphology, a particular grammatical theory of aspect, clock arithmetic, punctuality norms and a universal English timeline are **not** invented CEFR requirements. Apply only where a real versioned CEFR-linked descriptor/can-do and task require the temporal distinction.

## Controlled setup

Resolve a **real versioned** CEFR descriptor/can-do, blueprint, prerequisites, source-defined communicative task and outcome, target language and accepted varieties, source-valid temporal expressions and interpretations, rubric/evaluator versions, assistance rules, independent threshold, due reviews, delayed retrieval, genuinely unseen transfer and exit gate. Freeze the source-authored event facts and task-specific reference frames before method comparison: utterance time `S`, relevant reference time `R`, event time or interval `E`, event-order relations, completed/ongoing/habitual/planned status, date/locale/time-zone information *only where source-provided and task-relevant*, and any legitimately unresolved interpretation. Distinguish `BEFORE`, `AFTER`, `OVERLAPS`, `ONGOING_AT_REFERENCE`, `COMPLETED_BEFORE_REFERENCE`, `HABITUAL`, `PLANNED_NOT_CONFIRMED`, `AMBIGUOUS` and `UNKNOWN` as adjudicated task-state labels, not a demand for these technical terms from learners. For tasks without a source-required temporal contrast, return `NOT_APPLICABLE`.

Predeclare feasible, reversible instruction candidates `EVENT_SEQUENCE_CONTRAST`, `REFERENCE_TIME_TIMELINE`, `LISTEN_AND_RECONSTRUCT_ORDER`, `NARRATIVE_RECAST_WITHOUT_ANSWER`, `OPEN_UNSEEN_TEMPORAL_TASK` and `BALANCED_DEFAULT`. These may vary implemented and evaluable reading/listening/writing/speaking/free-production mix, explanation style, scaffolding, ordering, pacing, examples and review spacing, **not** shared CEFR objectives, source-valid temporal readings, independence thresholds or required receptive/productive evidence. A tutor-drawn correct timeline, highlighted reference anchor, supplied event order, recast that resolves the target distinction or scripted answer is assistance for the affected move. Ordinary source-permitted interlocutor clarification is task interaction; a scripted interlocutor leaking the target answer outside protocol is coaching. Rotate favorite, adjacent, neutral and unfamiliar contexts, sample alternative methods and never label learners permanently as “timeline,” “visual,” “fast” or other fixed types.

Use deterministic pseudonymous multi-session histories with injected seed/clock, immutable session-qualified event IDs and frozen source/task/rubric hashes. Capture the exact source utterances and source-valid interpretations; `S/R/E` anchors and authority; source-valid event ordering/status; first learner-authored temporal interpretation, explanation or communicative action; source-defined outcome; selected/assigned/**actually rendered** instruction and exact tutor-cue chronology; first-attempt quality, retries, hints/scaffold dependence, recurring error classes, optional latency only if calibrated, topic familiarity, practice dose, modality/accessibility and language variety; later independent delayed retrieval and genuinely unseen temporal transfer; and eligible/offered/rendered/completed/missing follow-up denominators. Distinguish a linguistic event-order error from date-calculation load, clock/time-zone confusion, speech-recognition noise, source ambiguity, inaccessible audio and missing evidence. Do not infer temporal comprehension from a lucky binary choice or the number of tense markers.

Evidence labels: `SOURCE_VALID_TEMPORAL_TASK`, `REFERENCE_ANCHOR_RESOLVED`, `EVENT_ORDER_PRESERVED`, `EVENT_STATUS_DISTINGUISHED`, `SOURCE_AMBIGUITY_RETAINED`, `FIRST_INDEPENDENT_TEMPORAL_DECISION`, `TUTOR_TIMELINE_CUE_EXPOSED`, `ASSISTED_TEMPORAL_DECISION`, `INTERLOCUTOR_TASK_CLARIFICATION`, `INTERLOCUTOR_COACHING_LEAK`, `INDEPENDENT_DELAYED_TEMPORAL_RETRIEVAL`, `INDEPENDENT_UNSEEN_TEMPORAL_TRANSFER`, `DATE_ARITHMETIC_CONFOUNDED`, `TIMEZONE_OR_LOCALE_CONFOUNDED`, `TOPIC_METHOD_CONFOUNDED`, `ACCESSIBILITY_CONFOUNDED`, `FOLLOWUP_MISSING`, `EVENT_REPLAY_DEDUPED`, `VERSION_CONFLICT_QUARANTINED`, `MODALITY_UNAVAILABLE` and `UNSUPPORTED`. ## Six synthetic longitudinal histories

- **A — Finished before arrival versus ongoing at arrival.** In a source-defined incident report, the inspection was completed **before** the coordinator arrived; in a contrast task it was **still underway when** the coordinator arrived. Learner A fluently describes both as completed at arrival, obscuring the relevant sequence. Learner B independently preserves the source-defined difference and communicates the correct next step. Accept target-language equivalents that express the distinction without an English past-perfect construction. If the source omits whether inspection ended, a justified clarification or retained uncertainty is valid.
- **B — Deictic time requires a source anchor.** A message says “next Friday” or “tomorrow morning,” but the task supplies an earlier message date distinct from the learner's current date. Learner A anchors it to device-now; learner B anchors it to the source speaker's timestamp and conveys the intended time where the locale makes it unambiguous. If “next Friday” has two source-valid regional readings, accept both with an appropriate clarification instead of silently choosing one. Do not turn date arithmetic or local holiday knowledge into a language mastery gate.
- **C — Tutor timeline made the answer visible.** Before a learner's first report, the tutor actually displays “First the payment cleared; only afterward was the booking confirmed.” Learner A repeats that correct order: the move is assisted. A later learner independently reconstructs a genuinely new multi-event timeline from source messages after meaningful delay. A timeline selected by policy but never rendered does not contaminate independence. A task-valid interlocutor asking “Before or after?” is not automatically answer-bearing coaching.
- **D — Early method advantage reverses on delayed transfer.** Matched early first unaided probes favor `REFERENCE_TIME_TIMELINE` over `EVENT_SEQUENCE_CONTRAST` for one learner. Later delayed unseen interactions with new event types, different reference anchors and source-equivalent communicative burden reverse the apparent advantage. Match or disclose tense/aspect difficulty, event count, reading load, numeracy/time-zone demands, topic familiarity, practice dose, feedback, modality, accessibility, language variety and rubric version. Reduce confidence, sample alternatives and log the **actually rendered** next method rather than assigning a permanent “visual learner” label.
- **E — Interests and modality do not erase skill obligations.** A learner sequences favorite-game events correctly but confuses an ongoing service appointment with a completed one in a neutral dialogue and misstates a repeated versus one-off community event in an unfamiliar context. Another learner completes an accessible written task; no spoken/listening evidence was observed. A caption that supplies the correct sequence is answer-bearing assistance. Rotate contexts, preserve due reviews and all source-required receptive/productive evidence; do not infer disability, device delay or typing speed as a temporal-language deficit.
- **F — Offline replay, shifted clocks and missing transfer.** Two offline sessions reuse a local event ID; a device clock is wrong; a tutor's correct sequence was actually rendered before the first learner response but uploaded afterward; a source message contains a timezone abbreviation with unresolved ambiguity; a rubric revision changes accepted readings; and a scheduled delayed unseen probe never completes. Use immutable session-qualified IDs, trusted source/utterance anchors, frozen task/rubric hashes and rendered-cue chronology. Deduplicate true replays, quarantine conflicting provenance, retain source ambiguity, keep follow-up unknown and require identical independence labels, review debt and next-method rationale across receipt-order permutations.

## Nine acceptance assertions

1. **Source-valid temporal construct before scoring.** For A–F emit versioned CEFR can-do, blueprint, prerequisites, source task/outcome, language/variety, `S/R/E` anchors, valid temporal readings, rubric/evaluator, assistance, independent threshold, delayed/unseen probes, due reviews and exit gate. Missing mapping or invented tense, clock or punctuality requirements yields `UNSUPPORTED`.
2. **Event order and reference time.** In A/B/F distinguish source-authored event-before/after/overlap relations from narration order and current device time. Credit meaning-preserving paraphrases; do not infer correct interpretation from a date token or isolated morphology.
3. **Aspect and communicative consequence.** In A/E distinguish ongoing, completed, habitual and planned-but-unconfirmed event status only where source-required, and score the relevant task action. Do not equate a grammatically polished sentence with the correct event status or penalize a target-language variety for not marking aspect the English way.
4. **Legitimate ambiguity and clarification.** In A/B/F preserve source-valid locale, deictic, timezone and event-boundary ambiguity; accept legitimate clarification and uncertainty. Do not resolve unknown anchors using system clock, learner geography or stereotypes; irreconcilable source/rubric versions fail closed.
5. **Actually rendered assistance and interlocutor provenance.** In C/E/F compare trusted tutor-cue render time with the first learner-authored temporal move. A displayed answer-bearing timeline, recast or caption makes the affected move assisted; assigned-but-unseen cues do not. Distinguish ordinary task clarification from coaching leaks.
6. **Independent delayed unseen transfer.** In C/D/F require a meaningfully separated session, new source events and reference anchors, first unaided temporal interpretation, source-defined communicative outcome and completed follow-up. Immediate retries, rehearsed substitutions, tutor-supplied sequences and missing probes cannot prove durable mastery; emit eligible/offered/rendered/completed/missing denominators.
7. **Comparable adaptive instruction and broad coverage.** In D/E match or disclose event count, temporal construct difficulty, source ambiguity, time arithmetic, topic familiarity, practice dose, feedback, channel, variety, accessibility and rubric. Preserve common CEFR objectives, noncompensatory receptive/productive mastery, due reviews and favorite/adjacent/neutral/unfamiliar exposure; interests softly affect examples only.
8. **Reversible hypotheses and deterministic replay.** In C/D/E/F emit feasible candidates, selected/assigned/actually rendered method, later independent evidence, uncertainty/confounds, exploration and next-choice rationale. Sparse/confounded histories use `BALANCED_DEFAULT`. Deduplicate session-qualified events, freeze source/rubric versions and prove receipt-order invariance for assistance, temporal interpretations, skill/review debt and next choice; quarantine irreconcilable provenance.
9. **Assertion-level audit without efficacy inflation.** For A–F emit source/task/rubric/evaluator IDs, frozen `S/R/E` and event-order annotations, first/final learner-authored messages, actual rendered assistance, communicative outcome, delayed/unseen denominators, confounds, replay equivalence and `PASS`/`FAIL`/`UNSUPPORTED` per assertion. Documentation CI alone cannot prove a shipped temporal-language evaluator, CEFR certification or improved human learning.

## Required evidence and release gate

An **executable fixture PASS** requires a named exact engine HEAD and command, deterministic seed/clock and multi-session histories, real source-resolved CEFR-linked temporal tasks, multilingual/variety-aware adjudicated event-time and aspect rubrics, frozen source/reference anchors, trusted actual tutor-cue provenance, first independent temporal decisions and task outcomes, independently completed delayed unseen transfer with denominators, comparable method/topic/modality/access exposure, protected skill/review obligations, replay-order permutations, reversible next-method traces and assertion-level verdicts. Missing source mapping, temporal anchor, validated reading, reliable modality or follow-up remains `UNSUPPORTED`/unknown, never invented proficiency.

Any claim that adaptive teaching **improves durable independent communication of temporal meaning** additionally requires separately reviewed real-learner longitudinal evidence against a credible balanced comparator, delayed unseen interactions, multilingual/variety and accessibility evaluator validation, human adjudication, privacy and subgroup-harm review and an ethically reviewed pilot. **A strong tutor helps a learner convey what happened when, and what is still happening, rather than simply reproduce tense forms.**
