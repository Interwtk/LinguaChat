# F123 — Flowchart branch, arrow, decision-path and independent communicative transfer

**Status:** design-only curricular acceptance fixture; **UNSUPPORTED** until executable assertions run on a named exact engine HEAD against real versioned CEFR-linked tasks, independently source-validated multilingual and accessible process diagrams, and delayed first-unaided transfer. This does **not** ship a flowchart parser, computer-vision/OCR system, safety-critical procedural assistant, accessibility conformance certificate, CEFR mastery or evidence of improved human learning. Pre-A1 frozen; A1–C2 unavailable.

**Contract:** `docs/curriculum/longitudinal-instructional-adaptation.md`. F33 protects genuinely unseen transfer; F37/F38 distinguish actually rendered assistance and tutor-origin mistakes; F49 protects accessibility construct validity; F50 preserves nonexclusive topic interests; F72 covers task goals and constraints; F81/F118 cover linguistic condition and negation scope; F82/F95 cover temporal sequencing; F84/F114 cover spatial deixis and visual referents; F85 covers obligation/authority; F103 covers critical-detail confirmation; F104 isolates method from task difficulty; F107 covers unreliable tutor feedback; F121 covers table/form field binding; F122 covers chart axis/legend/scale binding. **Distinct construct:** can the learner independently **explain or follow the source-authorized communicative route through a diagram of actions and decisions**, correctly binding a condition to its outgoing arrow, distinguishing required from optional steps, recognizing loops and endpoints, and communicating uncertainty where the actual rendered diagram does not determine a route? This tests language-mediated process comprehension, **not** an innate “visual learner” category, coding ability, diagram speed or generic logical aptitude. Source-authored examples must fit the learner's real CEFR can-do and age; do not invent a programming or engineering prerequisite.

## Six deterministic synthetic longitudinal histories

**A — A decision label belongs to an edge, not to a side of the page.** A fictional library-return flowchart starts at “Return book”, then asks “Is the library open?”. The source graph has YES → “Give book to librarian” → END and NO → “Use return box” → END. The source-authorized answer for a closed library is “Use the return box”. Learner A says “Give it to the librarian” because that action appears visually below the decision; learner B follows the NO-labeled arrow and explains the return-box action. Counterfactual: preserve the same node positions but **swap the two labeled edge destinations in the authoritative graph**; the correct answer changes. Merely mirroring the layout without changing edge connectivity must **not** change the answer. A source-valid nonvisual edge listing may support equivalent process comprehension if permitted, without claiming unaided visual decoding.

**B — Required prerequisites versus optional detours.** A fictional event-registration diagram has START → “Choose session” → “Complete registration” → “Receive confirmation” → END; a separately labeled optional “View venue map” branch rejoins before registration. Asked what must happen before confirmation, learner A lists only “Choose session” and jumps directly to confirmation; learner B preserves the required registration step while correctly identifying the map as optional. Counterfactual: the source version changes the map from optional to a required prerequisite with a validated arrow update; the acceptable path changes. Do not turn a suggested example into an external registration action or penalize a concise paraphrase that preserves every consequential requirement. A missing required edge makes the task UNSUPPORTED, not a learner failure.

**C — Loops, exits and stopping conditions.** A fictional vocabulary-card diagram says “Try the word” → decision “Correct independently?”; YES → “Continue to next card” → END, NO → “Review explanation” → “Try again”, with an explicit loop to the decision. Learner A assumes the NO branch also ends; learner B describes the retry and the YES exit. The task asks for the next action after an incorrect answer, **not** for a prediction that every learner will eventually succeed. Counterfactual: the source replaces the retry edge with a “Stop and ask for help” endpoint; the correct explanation changes. If the source loop has no specified exit for the current state, do not invent guaranteed termination. A correct copied tutor walkthrough remains assisted, not independent mastery.

**D — Rendering, multilingual labeling and accessible equivalence.** The authoritative diagram has a rightward arrow marked “NO” leading to “Use return box”. On a narrow phone, the arrowhead and label are cropped; OCR attaches “NO” to the other edge; a translation accidentally changes “unless approved” into “if approved”; and a color-only route has no independently validated noncolor equivalent. Preserve the authoritative graph **and the actual rendered artifact**. Quarantine affected learner-deficit and method comparisons as RENDER_ARROW_CROP, OCR_BRANCH_LABEL_CONFLICT, TRANSLATED_CONDITION_CONFLICT or unvalidated accessibility, rather than rewarding the tutor's guess or diagnosing poor process comprehension. A source-validated screen-reader linearization must explicitly state decision, branch label, destination and loop/re-entry; it can establish equivalent communicative process comprehension when the descriptor permits, but never automatically claims unaided visual-chart evidence or unobserved listening ability. If different modalities present conflicting routes, the task is not a reliable assessment until reconciled.

**E — Source versions, false certainty and assistance chronology.** A fictional school-club sign-up flowchart v1 routes “No places left” to “Join waiting list”; v2 changes the route to “Ask organizer for alternatives”. An answer to v1 is evaluated against **v1**, even after v2 arrives. A learner's first response is submitted at 10:00, while a tutor-highlight event is queued at 09:59 but **actually rendered at 10:01**; the first response remains unaided if no other help was rendered before it. A later copied answer is assisted. A duplicated offline event must be deduplicated by immutable session-qualified identity; a repeated local node ID in v2 is not the same source-qualified node. If the source has two unlabeled outgoing edges with no reliable condition binding, the valid outcome is clarification/UNSUPPORTED, not confident selection. Preserve partial correct language evidence when a specific source-path claim is unavailable.

**F — Reversible adaptation and genuinely new independent transfer.** Fictional learner A answers assisted route-tracing prompts correctly but fails delayed first-unaided decision explanations. After **actually delivered** CONDITION_EDGE_CONTRAST, A later describes the right branch on a new source-authored appointment-flow diagram with different start state, condition, edge layout and communicative goal. Learner B instead improves after LEARNER_VERBALIZES_NEXT_STEP on comparable tasks. Hold objective, target language/variety, baseline proficiency, diagram complexity (node/edge count, branch depth, loops), vocabulary, topic familiarity, accessibility route, prior exposure, rendered assistance, review interval and follow-up opportunity comparable. If A's method always uses two-node diagrams while B's uses dense branching graphs, flag METHOD_DIAGRAM_COMPLEXITY_CONFOUNDED and infer **no method winner**. Recoloring the same graph, relabeling actors while preserving the same condition-to-answer path, or asking the same rehearsed question is not unseen transfer. Track eligible/offered/rendered/completed/missing follow-ups; missing is not failure or success. Sufficient comparable repeated later outcomes may change the **next actually delivered** instruction for A versus B; contradictory outcomes reduce confidence and can reverse the choice. Preserve due reviews, receptive/productive skill balance, alternative exploration and topic diversity.

## Nine acceptance assertions

1. **Real CEFR and source-graph linkage.** A–F resolve versioned descriptor, blueprint, prerequisites, source-authorized graph and effective version, target-language/variety meanings, rubric/evaluator, first-unaided threshold, accommodations, protected skills, due reviews, delayed/unseen probes and exit gate. No invented programming, visual-spatial or advanced logic prerequisite.
2. **Decision-edge and direction binding.** A/C bind each decision's source-authorized YES/NO or other labels to the **correct directed edge** and reachable destination. Authoritative connectivity changes alter the expected route; layout mirroring alone does not.
3. **Prerequisites, optionality and terminal/loop semantics.** B/C preserve required steps, distinguish optional detours, follow loop re-entry and identify a source-supported exit. Never assume omitted steps, guaranteed termination or an invented path.
4. **Ambiguity, version and warranted clarification.** B/E preserve the source-effective graph, reconcile conflicting/unlabeled edges and accept source-valid uncertainty or clarification. Do not treat a later source correction as retroactive learner error or invent external actions.
5. **Actually rendered first-unaided provenance.** D/E record the first learner-authored response, exact source-qualified nodes/edges, retries and assistance **actually rendered before** the attempt. Queued, failed or post-answer tutor help is not retroactive assistance; copied routes cannot earn independent mastery.
6. **Multilingual, accessible and channel-valid assessment.** A/D independently validate language/variety condition readings, arrow/label binding, screen-reader linearization and accessible alternatives. Crops, OCR/translation contradictions or inaccessible representations quarantine affected claims, while valid equivalent communication evidence is retained without cross-modal overclaim.
7. **Delayed independent retention and genuinely unseen transfer.** A–F require meaningful separated learning opportunities and new source-authored diagrams with noncosmetic condition/edge/goal/distractor variation and no answer-bearing help. Report eligible/offered/rendered/completed/missing denominators; layout flips and cosmetic relabeling alone are insufficient.
8. **Reversible method selection and soft interests.** F records feasible, assigned and **actually delivered** methods, baseline/task comparability, confounds, uncertainty, exploration, contradictory outcomes, protected listening/reading/writing/speaking/free production, due reviews and exit gates. Interests shift context probability but cannot exclude adjacent, neutral or unfamiliar topics or required objectives; no permanent “visual learner” label.
9. **Exact-head deterministic reproducibility and bounded claims.** A–F emit seed/clock, named engine HEAD and runnable command, descriptor/source/graph/task/rubric/evaluator hashes, source-effective and actually rendered accessible artifacts, first/assisted responses, assistance/event ledger, counterfactuals, delayed/unseen denominators and **PASS/FAIL/UNSUPPORTED for every assertion**. Docs-only CI is neither an executable process evaluator, a reproducible runtime defect nor evidence of human-learning gains.

## Required evidence and release gate

An **executable fixture PASS** requires a named exact engine HEAD and reproducible command; real versioned CEFR-linked tasks; independently validated multilingual authoritative graphs and accessible representations; source-effective node/edge/branch bindings and actually rendered stimuli; first-unaided evidence; meaningful delayed independent retrieval and genuinely unseen diagram-to-communication transfer; comparable or explicitly confounded instructional alternatives; preserved protected skill/review/exit obligations; eligible/offered/rendered/completed/missing denominators; render/OCR/translation/version/replay/loop/edge-swap counterfactuals; and per-assertion verdicts. Unvalidated graph authority, unreliable rendering, unavailable accommodation, unresolved path or missing follow-up makes the affected claim **UNSUPPORTED/unknown**; preserve independently established partial language evidence.

Any stronger claim that adaptive flowchart/process instruction **improves durable independent communication** requires a separately reviewed, privacy-appropriate, multilingual, multivariety and accessibility-validated real-learner longitudinal study with credible comparison, attrition and subgroup-harm analysis and reproducible delayed outcomes. **A strong tutor helps the learner explain which action follows from which condition, not merely copy a highlighted arrow.**
