# F55 — Cross-linguistic scaffolding must not masquerade as independent target-language competence

**Status:** design-only curricular acceptance fixture; **UNSUPPORTED** until executable assertions run against a named exact engine HEAD. Not a reproduced defect, shipped multilingual evaluator, CEFR certification, or evidence of improved human learning. Pre-A1 remains frozen; A1–C2 remain unavailable.

**Contract:** `docs/curriculum/longitudinal-instructional-adaptation.md`. F54 distinguishes learner-initiated clarification from tutor-supplied repair. F55 distinguishes **using an already known language as an instructional bridge** from **independently performing the specific language/mediation task that the source-defined CEFR objective assesses**. Translation, cognate comparison, code-switching, bilingual explanations and first-language planning can be legitimate teaching tools. They do not automatically demonstrate unaided target-language listening, speaking, reading or writing. Conversely, do not penalize a source-valid plurilingual or mediation task merely because it involves more than one language. The versioned task construct decides what counts; there is no universal “target language only” rule.

## Controlled setup

Resolve a real versioned CEFR can-do, curriculum blueprint, item/task, target and bridge language(s), assessed construct, modality, evaluator/rubric and permitted supports **before** awarding credit. Freeze the required target-language communicative intent, linguistic burden, acceptable multilingual mediation where explicitly assessed, response language(s), independence boundaries, difficulty, delayed retrieval, unseen-context transfer, review debt and level exit gates. A source-defined bilingual mediation task may legitimately require conveying meaning between languages; an independent target-language production task may not be certified by an L1-only answer or by an unobserved machine translation. Do not invent blanket translation penalties, L1-use quotas, CEFR cutoffs or universal equivalence between text and audio.

Use deterministic synthetic pseudonymous learners, injected clock/seed and immutable event streams over genuinely separate learning sessions. Record objective/task/rubric/evaluator versions; target and bridge languages as task metadata rather than inferred identity; learner-authored first attempt, language and modality of each span/turn, semantic quality, retries, corrections, hint/model delivery, bilingual explanations, dictionaries, glosses, subtitles, automatic translation, transliteration, speech-to-text and text-to-speech exposure where actually known. Distinguish **comprehension of an L1 explanation**, **target-language recognition**, **independent target-language production**, **source-valid cross-language mediation**, **assisted reformulation**, **later unaided retrieval** and **unseen-context transfer**. Keep uncertainty explicit when the language of authorship, tool exposure, modality or scoring rule is unknown. Never infer nationality, ethnicity, home language, literacy, disability or “learning style” from an accent, name, spelling or preferred interface language. Minimize stored raw audio, text and sensitive biographical metadata.

Predeclare `BRIDGE_EXPLANATION_DELIVERED`, `L1_ASSISTED_PRACTICE`, `TARGET_LANGUAGE_INDEPENDENT`, `SOURCE_VALID_MEDIATION`, `TARGET_MODALITY_UNVERIFIED`, `TRANSLATION_EXPOSURE_UNKNOWN`, `COGNATE_TRANSFER_UNCERTAIN`, `INDEPENDENT_PROBE_PENDING`, `FOLLOWUP_UNKNOWN`, `RUBRIC_MISMATCH`, `EVENT_REPLAY_DEDUPED`, `UNAVAILABLE` and `UNSUPPORTED`. A polished target-language sentence after a displayed translation is not an unaided first attempt. A bilingual answer that a mediation rubric explicitly permits is not automatically wrong.

## Six synthetic histories

- **A — Same correct target sentence, different help provenance.** Learner A independently writes an appropriate target-language request on the first attempt. Learner B first composes the request in a familiar language, receives a full target-language translation from the tutor and copies it. Both final requests are identical and pragmatically correct; preserve A's independent production and B's assisted practice separately. A later unaided task, not the copied answer, determines whether B has transferred the target form. If the source instead assesses assisted translation practice, report that construct rather than relabeling it as independent production.
- **B — Helpful bilingual explanation, weak independent retrieval.** A learner initially confuses a target-language tense/aspect distinction. A short bridge-language contrast and worked example improve immediate recognition and scaffolded responses. In a genuinely later session with intervening material, an unseen target-language writing task without glosses or translation reveals the same error. Record the instructional benefit, original recurring error, actual interval and incomplete independent mastery; retain due review and source-defined exit obligations. A mere calendar boundary does not establish delayed retrieval.
- **C — Legitimate mediation versus substituted target production.** Task C1 has a source-validated plurilingual mediation rubric requiring the learner to relay a message accurately across languages for a specified audience; an independently authored bilingual reformulation may meet that task. Task C2 explicitly assesses unaided target-language oral interaction; the learner submits an L1 summary or translated written transcript instead of the required spoken response. Score C1 only against its authorized mediation construct and C2 only against its target-language oral construct. If the actual rubric or speech capability is absent, return `UNSUPPORTED`/`UNAVAILABLE`, not a fabricated pass or universal code-switching penalty.
- **D — Cognates, false friends and unfamiliar transfer.** A learner recognizes familiar cognates in a topic close to their bridge language and obtains high immediate reading scores. On an unseen context with a deceptive cognate, they misinterpret intent; another learner accurately infers meaning from target-language context without translation. Preserve word-level semantic evidence, topic familiarity, source-valid alternatives and first-attempt errors. Do not treat shared orthography, fast responses or language similarity as proof of productive command, and do not infer a learner's native language from a mistake.
- **E — Reversible method choice without fixed multilingual types.** Two learners pursue the same versioned can-do, difficulty and independent evidence requirements. A shows stronger later unaided transfer after concise target-language examples; B initially shows stronger transfer after brief bilingual contrasts followed by scaffold fading. Counterbalance task difficulty, topic familiarity, method order, cognate load, bridge-language comprehension and exposure time; sample both approaches. Later independent probes reverse B's apparent advantage. Lower confidence and revise the provisional method choice while retaining alternative sampling and balanced reading/listening/writing/speaking where supported. Never classify either learner as a permanent “translation learner” or “immersion learner.”
- **F — Late translation, mixed-language offline replay and stale rubric.** An offline learner response is drafted before a translation tool is opened; a later target-language revision occurs after a model translation is displayed, but that exposure event arrives at the server after the revision. A duplicated upload reuses the local turn ID in a second session; an old task rubric allows bilingual mediation while a new task version requires unaided target-language production. Replay both receipt orders with stable session-qualified event IDs, trusted occurrence/**delivery** chronology and immutable task/rubric versions. Preserve the genuinely pre-exposure first attempt, classify the post-exposure revision as assisted where warranted, deduplicate submissions and quarantine unsupported cross-rubric migration. If delivery order or tool use cannot be established, disputed independent credit stays `UNSUPPORTED`; never assume the learner saw a translation merely because a tool was installed.

## Nine acceptance assertions

1. **Task construct and source first.** For A–F emit exact versioned CEFR can-do, blueprint, item/task, target/bridge languages, response language rules, assessed modality, evaluator/rubric, permitted mediation and support, independent evidence, delayed retrieval, transfer and exit requirements. Missing rules or unimplemented modalities yield `UNSUPPORTED`/`UNAVAILABLE`, not invented credit.
2. **Translation provenance changes independence, not semantic quality.** In A, retain each learner's first target-language attempt, L1 draft, delivered translation/model, final answer and assessed construct. Identical final target-language sentences must not collapse independently authored production into copied practice, nor erase the legitimate value of assisted practice.
3. **A bridge can teach without certifying mastery.** In B, record bilingual explanation delivery, immediate gains, recurring error type, scaffold fading and later eligible/completed/missing unaided probes. Do not promote L1-assisted recognition to durable independent target-language control; preserve review debt and unchanged gates. Missing follow-up is unknown, not a failure.
4. **Mediation is a distinct source-valid construct.** In C, permit independent multilingual mediation only when the exact rubric assesses it. Do not substitute an L1 summary, machine-translated text or written transcript for a source-required independent target-language oral performance; do not impose a universal monolingual rule on legitimate mediation.
5. **Cognate familiarity is not general competence.** In D, distinguish source-validated semantic understanding, false-friend errors, contextual inference, target-language form and actual unseen-context transfer. Do not infer productive skill, identity, home language or durable comprehension from a single cognate-rich success.
6. **Instructional hypotheses are longitudinal and reversible.** In E, log available/selected/**delivered** bilingual contrast and target-language-only options, bridge comprehension, uncertainty, first attempts, hint dependence, independent delayed retrieval and unseen transfer. Compare comparable tasks, sample alternatives, reverse or weaken a method preference on contradictory outcomes, and preserve required skill coverage; never assign a fixed language-learning type.
7. **Interest personalization and accessibility remain separate.** Across A–F, interests softly weight examples but cannot remove adjacent, neutral or unfamiliar contexts, override explicit topic boundaries, skip CEFR objectives, change task burden or waive independent review. Captions, replay, slower audio, dictionaries, transliteration and translation must be distinguished by what was actually delivered and by the source rubric; accessibility affordances are not automatically coaching, nor do they certify unsupported listening/speaking modalities.
8. **Deterministic replay preserves source and exposure.** In F, stable session-qualified IDs, immutable source versions, delivered-cue chronology and deduplication must converge across both event arrival orders on first/final quality, bridge support, independent/assisted/mediation classifications, review debt and provisional policy. Unknown exposure or rubric migration cannot retroactively manufacture independent credit.
9. **Honest evidence and release boundary.** For each history report target/bridge languages, exact task/rubric, actual modality, learner-authored first/final attempts, translation/cue provenance, legitimate mediation, semantic and linguistic outcomes, assigned/delivered methods and uncertainty, topic/skill rotation, eligible/completed/missing delayed probes, unseen transfer and per-assertion `PASS`/`FAIL`/`UNSUPPORTED`. Documentation or CI success alone does not establish a shipped multilingual tutor, validated CEFR mastery, fair cross-language evaluation or improved durable learning.

## Required evidence and release gate

For A–F publish the **exact tested engine HEAD**, executable test command, injected clock/seed, immutable synthetic event streams in both receipt orders, versioned CEFR blueprint/task/evaluator/rubric, explicit source rules for multilingual mediation and permitted supports, first/final learner-authored responses with target/bridge-language provenance, actually delivered translation/model/gloss/audio affordances, source-valid scoring, eligible/completed/missing delayed independent probes and unseen transfer, method alternatives/confidence, unchanged review/exit obligations and per-assertion verdicts. If bridge-language comprehension, authored-language attribution, cue delivery, authorized mediation or required modality is unverified, report the limitation rather than fabricating independent competence.

Any claim that bilingual contrasts, translation-assisted practice or target-language-only instruction **improves durable independent learning** requires separately reviewed longitudinal comparisons with equivalent tasks, uncertainty-aware exploration and ethically reviewed real-learner evaluation. **A strong tutor may use a language the learner already knows to teach, but must verify what the learner can later do independently in the language and modality the actual objective requires.**
